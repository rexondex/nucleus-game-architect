# Virtual Forest

웹 기반 3D 생활형 게임 프로젝트입니다. 초기 개발 기반은 AI가 일관된 구조로 확장하도록 타입·린트·모듈 경계·콘텐츠 검사를 포함합니다.

## 기술 스택

- TypeScript
- Vite
- React
- React Three Fiber (Three.js 기반)

## 시작하기

```sh
npm install
npm run dev
```

## 구조 검사와 빌드

```sh
npm run check
npm run build
```

`npm run check`는 타입, ESLint, 모듈 의존 경계, 의상 카탈로그와 에셋 경로를 검사합니다.
